# Record the real demonstration

Start the local server, then open http://127.0.0.1:4173/demo.html in an ordinary Chrome or Edge browser window.

The recorder embeds the actual app in a separate demo session. It does not replace your normal saved session, generate mock footage or automatically answer challenges. English timed presentation cues accompany the live app. Audio is not requested. Recording stops at 2:50.

1. Start recording and choose only the SkillStrata tab or window in the browser's sharing picker.
2. Follow `DEMO-SCRIPT.md`, using the real controls and fictional example answers.
3. Stop recording. The video is saved to the local project's `recordings` folder, which Git ignores. The Download button is also available.
4. Play the full file. Check that the app is visible and readable, that no private data appears, and that the duration is below three minutes.
5. If the first-frame warning says the capture is black, do not publish it. Select the browser tab instead of a protected/unsupported display surface and retry in an ordinary browser.
6. Upload only a verified video to your YouTube or Vimeo account. Copy its public URL into Devpost.

Recordings are not sent to external services by this app. Local recording files are not deleted by Reset session; remove unwanted files separately.
